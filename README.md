# Agentic AI Projects 🤖

This repository contains my Agentic AI class activities and projects. Each project is maintained in a separate folder with its own code and README.

## Projects

### 1. TaskPilot — Assignment Priority Agent

A Python-based rule-driven agent that helps students prioritize assignments based on deadlines and difficulty.

Features:
- Collects assignment details
- Calculates priority scores
- Ranks assignments
- Recommends which assignment to complete first

Folder: `assignment-1/`

### 2. College Library Chatbot

A Python chatbot created as part of Class Activity 2, with an original version and a GitHub Copilot-improved version.

Features:
- Checks a fixed inventory of five books
- Identifies available and borrowed books
- Handles books not present in the inventory
- Includes original and improved implementations

Folder: `library-chatbot/`

### 3. TravelPilot — Travel Planning Agent

A travel planning application with a web frontend and FastAPI backend.

Features:
- Travel preference memory
- Budget estimation and validation
- Automatic budget re-planning
- LLM-generated travel summary with fallback
- Human approval demonstration
- Architecture and workflow diagrams

Folder: `travel-agent/`

## Technologies Used
