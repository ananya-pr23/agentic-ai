# TaskPilot 🤖

A simple Python-based assignment priority agent.

TaskPilot helps students decide which assignment to work on first based on:

* Assignment deadline
* Assignment difficulty

It calculates a priority score, ranks the assignments, and recommends what to work on first.

## How to Run

```bash
python taskpilot.py
```

## Tech Used

* Python
* `datetime`
